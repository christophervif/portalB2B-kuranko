Crear productos para WooCommerce desde la lista de una marca

Sube la lista de precios tal como la manda la marca o el distribuidor (repuestos, accesorios, ropa). Cada fila se convierte a nuestro nombre Marca - Tipo - Descripción precisa - Información adicional - Variante, se agrupan las variantes (talla, color, medida) y se asigna una categoría que ya existe. Lo que no calza queda con alerta para que lo elijas a mano o crees una categoría nueva. Al final descargas tu plantilla CREACIÓN PRODUCTOS WOOCOMMERCE lista para importar.

Traducciones (para trabajar sin IA)
Una por línea: Black = Negro. Se usan para la descripción y los colores, y las de la sección # Tipos también como 2.º segmento del nombre (Jersey = Polo). Sirven para todas las marcas. Las nuevas se aplican al procesar una lista, o con «Aplicar traducciones» sobre los marcados.
